Como criar seu Banco Gratuito no Supabase (Em 1 Minuto)

  1. Crie uma conta gratuita em supabase.com e clique em New Project.
  2. No menu Project Settings > API, copie a URL e a anon public key e cole nos campos acima.
  3. No menu Storage, crie um Bucket público com o nome exato pdfs.
  4. No menu SQL Editor, execute: create table proposicoes (id text primary key, category text, title text, author text, status text, notes text, fileName text, size text, pdfData text, date text);
