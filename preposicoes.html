1. O PDF não vai direto entre aparelhos

Dispositivos na internet normalmente não conseguem conversar diretamente sem um servidor intermediário (por causa de roteadores e firewalls/NAT). O Dispositivo A envia o PDF para um Cloud Storage público.

2. O Servidor WebSocket notifica

Assim que o upload termina, o notebook envia uma mensagem curta via WebSocket ao Servidor: "Atenção, publiquei o PDF X na URL Y". O servidor repassa essa mensagem na hora para o Dispositivo B.

3. Dispositivo B baixa e mostra

Ao receber a notificação, o código JS do Dispositivo B atualiza o endereço (src) do seu visualizador para a URL do PDF, renderizando o arquivo instantaneamente sem dar refresh!
